# Pearl Rig Control

Датчики используют API OneZeroMiner 1.8.3 `127.0.0.1:3001` и `nvidia-smi`.
Хешрейт в API задан в H/s; интерфейс показывает TH/s. Счётчики шар берутся
из `devices_accepted_shares` / `devices_rejected_shares` для каждой карты,
а общие счётчики рига показываются отдельно. Отсутствующие значения остаются `null`.
Источник и время получения показаний видны в панели; данные API старше 20 секунд
считаются устаревшими. Температуры памяти и hotspot не подменяются температурой ядра.

Панель также показывает общий текущий расход двух GPU в Вт и кВт, накопленную
энергию в кВт·ч по измерениям `nvidia-smi`, стоимость электроэнергии по введённому
тарифу и стоимость PRL по введённому курсу. Курс PRL и тариф хранятся только в
браузере пользователя; они не выдаются за данные пула. Накопление кВт·ч идёт
только при наличии реальных показаний мощности и помечено как измерение этой
панели, а не показание бытового счётчика.

Курс PRL/RUB не вводится вручную: сервер панели обновляет PRL/USD из официального
API Kryptex (`/api/v1/coin/prl/price/chart`) и USD/RUB из API Банка России
(`https://www.cbr.ru/scripts/XML_daily.asp`). При недоступности источника сумма в
рублях показывает «нет свежего курса», а не старое или выдуманное число.

Кнопка «Обновить данные» принудительно запрашивает свежий баланс Kryptex и
телеметрию. «Полный экран» использует стандартный Fullscreen API браузера.

## Проверка

```sh
npm ci --ignore-scripts
npm test
npm run lint
npm run build
```

В Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/telemetry.Tests.ps1
```

Опция `-ExecutionPolicy` действует только для этого процесса; постоянная политика Windows не меняется.
Тесты используют записанный ответ API и не запускают майнер, не меняют частоты или защиту Windows.

`src/agent/telemetry.ps1` — общий конвертер для GUI и генератора BAT.
`src/utils/telemetry.ts` обрабатывает резервный прямой опрос API веб-панелью.
Схема локального моста датчиков — версия 4; старый мост версии 3 не используется
для новых шкал. Локальная веб-панель после сборки: `node scripts/serve-panel.mjs`,
адрес `http://127.0.0.1:3000/`. Мост GUI должен работать на порту 3002.

PowerShell-часть BAT поддерживает `-ReadOnly`: только мониторинг, без управления
процессами и GPU. Открытие обычного GUI само по себе тоже не включает watchdog
для уже работающего майнера; управление требует явной локальной команды.

Изменения датчиков не являются полной проверкой остальных функций управления,
автоперезапуска или установщика.
